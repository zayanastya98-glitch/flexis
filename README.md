# Бот для отработки чанков

Telegram-бот на Cloudflare Workers с базой данных Cloudflare D1. Отдельный сервер не нужен.

## Что умеет

**Студент:** входит по личному ID, добавляет свои чанки, тренирует карточки, заканчивает фразы и выбирает ежедневные уведомления и их время.

**Преподаватель:** создаёт студентов, добавляет лексику одному или всем, отправляет заметки с уроков и получает ответы студентов.

## Настройка в Cloudflare

1. В разделе D1 создай базу `flexis-db` и укажи её ID в `wrangler.toml`.
2. Подключи этот репозиторий в Workers & Pages. Имя воркера должно быть `flexis`.
3. В настройках воркера добавь секрет `BOT_TOKEN` с токеном от BotFather.
4. Открой адрес `https://адрес-воркера/setup`. Должно появиться сообщение «Готово!». После каждого обновления кода, где меняется список событий от Telegram, открой его снова.
5. Напиши боту `/myid` и добавь полученное число как секрет `TEACHER_ID`.

Токен храни только в секретах Cloudflare. Никому его не отправляй и не загружай на GitHub.

## Команды преподавателя

- `/addstudent Анна` — создать студента и получить его ID
- `/students` — список студентов и их ID
- `/add` — добавить лексику одному, нескольким или всем студентам
- `/list` — посмотреть лексику студента
- `/delete 12 15 20` — удалить чанки по номерам
- `/note` — отправить студенту заметку с урока
- `/reply` — написать студенту от своего имени
- `/stats` — активность студентов: вход, чанки, карточки, ответы
- `/dupes` — найти повторы в лексике студента
- `/reset` — обнулить прогресс студента: лексика и заметки останутся
- `/answers` — последние ответы студентов
- `/cancel` — отменить добавление лексики
- `/logout` — выйти из аккаунта студента и освободить его ID

## Формат лексики

Каждый чанк пишется с новой строки:

```
чанк | перевод | пример для студента | начало фразы
```

Например:

```
used to | раньше (привычка) | I used to teach in a school. | I used to...
make a decision | принять решение | I made a decision to move to Istanbul. | The best decision I've ever made was...
```

Обязателен только чанк. Если не указать начало фразы, чанк не попадёт в задания «Закончи фразу».

Студент тоже может добавить чанки кнопкой «➕ Добавить чанк». Они сразу попадают в его карточки, а преподаватель получает уведомление. Исправить чанк можно через `/list`, `/delete` и `/add`.

Карточка случайно показывается на английском или на русском. Без перевода она всегда будет на английском.

## Автопроверка ответов

Если в Cloudflare добавлен секрет `ANTHROPIC_API_KEY`, ответы на задания «Закончи фразу» проверяет Claude Haiku 5.5. Студент получает комментарий, а Настя видит и ответ, и проверку. Лимит: 30 проверок на студента в сутки. Без ключа или при ошибке API ответ просто сохраняется. Под новым ответом есть кнопка «Ответить», а команда `/reply` подходит и для старых ответов.

## Повторы

При добавлении бот не сохраняет точные повторы и предупреждает о похожих чанках, но всё равно их добавляет. Проверка работает без ИИ: она сравнивает написание, а не смысл, поэтому чанки с разными словами, но одним значением не заметит. Команда `/dupes` проверяет 150 последних чанков студента.

## Квиз и прогресс

Кнопка «🧩 Квиз» присылает опрос Telegram: чанк на русском и четыре варианта на английском из лексики студента. Ответы считаются в прогрессе. Нужно минимум 4 разных чанка и хотя бы один с переводом.

Кнопка «🏅 Прогресс» показывает серию дней подряд, результаты квиза, число карточек и бейджи: «Первые шаги», «Автор», «Практик», «Память», «Квиз-мастер», «Неделя подряд» и «Месяц подряд». Серия считается по дням, в которые студент заходил в бота, по времени Стамбула.

## Активность

`/stats` показывает, когда студент последний раз заходил в бота, сколько чанков у него есть и сколько он добавил сам, сколько карточек прошёл и сколько дал ответов. Сброс через `/reset` обнуляет счётчик карточек, а добавленные сами чанки считаются по всем добавлениям.

## Заметки с уроков

Команда `/note` отправляет заметку выбранному студенту с сегодняшней датой. Студент видит список заметок с датами (до 90 последних) по кнопке «📝 Заметки».

## Уведомления

Ежедневный «Чанк дня» выделен жирным. Под ним есть короткая строка: «🔥 Серия: N дн. подряд. Продолжим?», если серия не прервалась, или «🏁 Начни свой марафон», если это первый день.

Расписание запускается раз в минуту и обрабатывает до 10 студентов, чтобы не выйти за лимиты бесплатного тарифа. Если у многих студентов одно и то же время, сообщения могут прийти с задержкой в несколько минут.

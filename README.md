# Бот для отработки чанков

## Что умеет

**Студент:** входит по личному ID, тренирует карточки, заканчивает фразы и выбирает ежедневные уведомления и их время.

**Преподаватель:** создаёт студентов, добавляет лексику одному или всем и получает ответы студентов.

## Запуск на компьютере

1. Установи Python с python.org.
2. Открой терминал в папке бота и выполни `pip install -r requirements.txt`.
3. Скопируй `.env.example` в файл `.env` и вставь токен от BotFather. Строку `TEACHER_ID` пока оставь пустой.
4. Запусти бота: `python bot.py`.
5. Напиши боту `/myid`, вставь число в `TEACHER_ID` и перезапусти бота.

Файл `.env` содержит токен. Никому его не отправляй и не загружай на GitHub.

## Запуск на хостинге

Боту нужен сервер, который работает постоянно. Настройки зависят от хостинга:

- Команда запуска: `python bot.py`.
- Переменные окружения: `BOT_TOKEN`, `TEACHER_ID`, `TIMEZONE`, `DB_PATH`.
- Нужен постоянный диск. Укажи в `DB_PATH` путь на этом диске, например `/data/bot.db`, иначе данные студентов могут исчезнуть при перезапуске.

## Команды преподавателя

- `/addstudent Анна` — создать студента и получить его ID
- `/students` — список студентов и их ID
- `/add` — добавить лексику
- `/list` — посмотреть лексику студента
- `/delete 12` — удалить чанк по номеру
- `/answers` — последние ответы студентов
- `/cancel` — отменить добавление лексики

## Формат лексики

Каждый чанк пишется с новой строки:

```
чанк | перевод | пример для студента | начало фразы
```

Например:

```
used to | раньше (привычка) | I used to teach in a school. | I used to...
make a decision | принять решение | I made a decision to move to Istanbul. | The best decision I've ever made was...
```

Обязателен только чанк. Если не указать начало фразы, чанк не попадёт в задания «Закончи фразу».
